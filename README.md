# Portfólio · Júlio Guedes

Portfólio de analista de logística e desenvolvedor full stack: sistemas de frota, rastreio de cargas, manutenção industrial e dashboards de Power BI.

**Site:** [julio-portifolio.pages.dev](https://julio-portifolio.pages.dev/) · **LinkedIn:** [julio-guedes-](https://www.linkedin.com/in/julio-guedes-)

## O que tem no site

- Projetos com telas reais (dados fictícios): GestFrota, Rastreio, ProdManutenção e dashboards de Power BI
- Roteirizador interativo: compare sua rota com a do algoritmo
- Estoque em 3D (three.js) e hero que alterna entre Analista e Desenvolvedor
- Experiência, formação e resultado comprovado em logística

## Tecnologias

HTML, CSS e JavaScript puros em um único `index.html`, servido e empacotado com [Vite](https://vite.dev).
three.js e Google Fonts via CDN. Deploy no Cloudflare Pages.

## Rodando localmente

```bash
npm install
npm run dev       # desenvolvimento
npm run build     # gera dist/
npm run preview   # serve o build
```

## Estrutura

```
index.html   página inteira (markup, estilos e scripts)
public/      imagens, vídeos e dashboards usados no site
```

## Privacidade

Todas as telas e dashboards usam dados fictícios. O comprovante de resultados tem nomes de fornecedores borrados.
