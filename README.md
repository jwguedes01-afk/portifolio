# Portfólio · Júlio Guedes

Site estático em um único `index.html` (HTML, CSS e JS inline), servido pelo Vite.
Imagens em `public/`. Deploy no Cloudflare Pages.

```bash
npm install
npm run dev     # desenvolvimento
npm run build   # gera dist/
```

Dependências externas por CDN: three.js e Google Fonts.
